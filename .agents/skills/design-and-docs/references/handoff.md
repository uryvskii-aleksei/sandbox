# Continuation handoff

When work pauses, transfers or approaches context compaction, preserve the current state in chat: task, date, absolute workspace, branch/HEAD or unborn status, dirty/new paths, completed outcomes, settled decisions, valid checks, blockers and the next concrete action. Keep temporary evidence paths only when the next runtime can access them. Essential conclusions must remain understandable without those files.

Update an existing authorized PR plan rather than creating a second plan. Lasting research decisions stay in their owning design or issue. Do not commit or push solely to save progress unless already authorized. Completed work needs no extra handoff file.

On resume, read the latest handoff and current issue/PR or design, then reconcile the actual workspace, source commits and pending external operations. Preserve human edits. Verify whether a timed-out operation already succeeded before retrying it. Continue from the first incomplete outcome instead of repeating settled investigation.
