# Memo

## 1. Приложение

Memo — новое название MindAssistant. Исходники приложения находятся в `apps/memo`, npm-пакеты — `@sandbox/memo` и `@sandbox/memo-web`.

Личное пространство для заметок, семейных деревьев, конспектов, ретроспектив и задач. Быстрые записи попадают во «Входящие», поиск находит содержание во всех проектах, а карточки связываются перетаскиванием на полотне. У записи может быть несколько родителей и потомков. Есть стартовые шаблоны, разметка полотна, режим списка, корзина и экспорт проекта с файлами. [Типовые сценарии](workspace.md#6-типовые-сценарии).

Редактор автоматически сохраняет изменения и оставляет черновик на устройстве при сбое. В карточке — упорядоченные сворачиваемые группы и поля: текст, ссылка, дата, изображение, видео, аудио. Поддерживаются регистрация, вход, приватные проекты, загрузка медиа до 5 МБ и превью публичных ссылок. Внешний ИИ не используется. [Сценарии, хранение и совместимость](workspace.md).

Новый стек: React + TypeScript + Vite, PHP + MySQL. Локально используются PHP 8.4 и MySQL 8.4, веб-PHP на Timeweb — 8.2. Старые Angular/Go-исходники с лицензиями находятся в `legacy/` и не подключены к npm workspaces.

## 2. macOS и Docker

Нужны Node.js 24+, npm и запущенный Docker Desktop с Compose. React/Vite работает на macOS. PHP/Apache и MySQL — в Docker. Порт MySQL наружу не открыт, API привязан к `127.0.0.1:8081`.

Из корня Sandbox:

```bash
npm ci
npm run dev:memo
```

Откройте `http://127.0.0.1:5173/memo/`. Первый запуск создаёт игнорируемый `.env` со случайным локальным паролем, собирает контейнер, запускает MySQL, применяет схему и запускает Vite. Данные сохраняются в Docker volume `sandbox-mind-assistant_mysql-data`. При остановке Vite контейнеры продолжают работать.

```bash
npm run services:down --workspace=@sandbox/memo
npm run services:up --workspace=@sandbox/memo
npm run db:migrate --workspace=@sandbox/memo
```

`services:down` сохраняет volume. `docker compose down --volumes` удаляет локальные данные, поэтому для обычной остановки он не используется. Изменения React обновляются через Vite. PHP подключён в контейнер как исходники только для чтения, изменения видны при следующем запросе. Dockerfile требует пересборки образа после изменения зависимостей PHP.

## 3. Проверки и сборка

```bash
npm run check --workspace=@sandbox/memo
npm run build:memo
npm run test:memo
```

Интеграционный тест создаёт отдельный Compose-проект со случайным паролем, свободным портом и собственной БД. Проверяет синтаксис PHP, повторное применение схемы, авторизацию/CSRF, владение данными, все типы полей, порядок, сохранение между сессиями, конфликты версий, транзакционный rollback, удаление связанных карточек и безопасность медиа/URL-превью. Дополнительно запускает собранный артефакт в Apache, проверяет вложенные маршруты, ресурсы, запрет доступа к серверным файлам и повторяет API-сценарий под `/memo/api`. После проверки удаляет только свои тестовые контейнеры и volume. Рабочая БД приложения не очищается.

Сборка `dist/` содержит React, PHP API, схему и защищённые Apache-каталоги. Исходники legacy, Docker и `.env` туда не попадают.

## 4. Устройство API

Frontend обращается к `/memo/api/`. Vite проксирует запросы в локальный Apache. PHP использует native session с HttpOnly/SameSite cookie и CSRF-токен для записи. Запросы PDO параметризованы, доступ к проектам/карточкам/файлам проверяется по владельцу. Полное сохранение карточки выполняется в транзакции и проверяет версию для защиты от перезаписи устаревшего состояния.

Файлы хранятся в MySQL и выдаются только авторизованному владельцу. URL-превью ограничено публичными HTTP(S)-адресами с проверкой редиректов и фиксацией IP. Не предусмотрены сброс пароля, email-верификация, общий доступ и синхронное редактирование несколькими пользователями.

## 5. Timeweb

На хостинге Docker и Node не нужны: Apache/PHP обслуживает API, MySQL хранит данные, React загружается как готовые файлы. Базовый путь сборки — `/memo/`. Целевой адрес — [cj999935.tw1.ru/memo/](https://cj999935.tw1.ru/memo/). Серверное назначение устанавливается по SSH. Проверки релиза используют HTTPS технического домена. Проверенный коммит `main` выпускается командой `npm run release:memo`. Actions публикует артефакт, задание Timeweb выполняет backup, миграцию и проверку HTTPS. Подробности и восстановление — в [инструкции поставки](deployment.md).

## 6. Старые данные

Прежние Angular/Go-репозитории и лицензии сохранены в `legacy/`, дампы — приватно вне Git, см. [происхождение](../../docs/imports/README.md). Исторические данные перенесены в аккаунт владельца: 3 проекта, 5 карточек, 2 группы и 2 текстовых поля. В исходном дампе был один пустой проект, а карточки ссылались на два отсутствующих проекта. Для каждого отсутствующего исходного проекта создан отдельный восстановленный проект, поэтому записи не смешаны.

[Миграция](migration.md) описывает конвертацию и идемпотентный импорт с явным владельцем. Повтор не перезаписывает пользовательские изменения. SQL-копия после переноса восстановлена в изолированном Docker-проекте с проверкой API и целостности всех таблиц. [Проверка восстановления](recovery.md) воспроизводится отдельно от production.

## 7. Оформление

React сохраняет синюю палитру старого приложения (`#1f408a`, hover `#3458a7`, active `#15306b`) и пунктирные SVG-связи. На полотне записи и папки показывают название на белых карточках с синей верхней кромкой. Круглые точки служат для перетаскивания связей и сохраняют размер при масштабировании. При `prefers-reduced-motion` движение связей отключено. На узком экране доступны основная навигация, быстрый ввод, выход из аккаунта и список записей.

## 8. Совместимость после переименования

Имя Compose-проекта `sandbox-mind-assistant`, volume `sandbox-mind-assistant_mysql-data`, имена базы и пользователя `mindassistant` и cookie `mind_assistant` сохранены для доступа к прежним данным и сессиям. При первом `npm run dev:memo` прежний `apps/mind-assistant/.env` копируется в `apps/memo/.env` с правами `600`, если нового файла ещё нет. Существующий новый файл не перезаписывается.

Конфигурация PHP задаётся через `MEMO_CONFIG`. Прежний `MIND_ASSISTANT_CONFIG` поддерживается, если новая переменная не задана. Для тестов используются `MEMO_TEST_URL` и `MEMO_TEST_PHP_VERSION`, для SSH — `MEMO_SSH_CONFIG`. Их прежние варианты с префиксом `MIND_ASSISTANT_` также поддерживаются.

Публичный адрес меняется на `/memo/`. Приватный серверный каталог `.sandbox/mind-assistant`, GitHub Environment, группы блокировки, служебные ветки выпуска и идентификаторы артефактов остаются прежними. Это контракт с receiver и резервными копиями. Сохранённые старые ссылки на медиа открываются через новый API. Команды разработки и выпуска используют имя `memo`. Архивные исходники и формат старого импорта сохраняют историческое имя.

## 9. Компоненты интерфейса

Общие элементы frontend находятся в `frontend/src/ui/`: `Button`, `IconButton`, `Icon`. Они используют существующие стили Memo, нативные HTML-кнопки и SVG-иконки. Иконки декоративны, доступное имя задаётся кнопке. Новые одинаковые элементы следует собирать из этих компонентов. Отдельный пакет для других приложений пока не выделен.
