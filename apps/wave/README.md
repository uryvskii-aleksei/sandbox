# Wave

Видеорадио Amodu. Запустите первый клип кнопкой Play на заставке. После этого управление откроется в нижней панели. Подсказки показывают клавиши управления: пробел — воспроизведение или пауза, ← и → — предыдущий и следующий клип, L и D — лайк и дизлайк, I — сведения о клипе, F — полноэкранный режим. Стартовый клип выбирается случайно с учётом имеющихся оценок. После него включается следующий. Можно поставить клип на паузу, вернуться к предыдущему и оценить текущий. Похожие клипы появляются чаще после лайков и реже после дизлайков. При подборе учитываются исполнитель и теги. До старта используется синий Memo. Каждый клип задаёт общий акцент для кнопок и звуковой анимации. Волны, дуги, точки и штрихи реагируют на бас и частоты. Начальная форма меняется при запуске клипа, а во время воспроизведения сцены плавно сменяют друг друга. При системной настройке уменьшенного движения фон статичен.

## 1. Локальный запуск

Нужен PHP 8.2+ с PDO SQLite. Из корня монорепозитория запустите:

```bash
wave_data="$(mktemp -d)"
WAVE_DB_PATH="$wave_data/wave.sqlite3" php -S 127.0.0.1:4182 -t apps/wave/site apps/wave/preview.php
```

Откройте [главную Amodu](http://127.0.0.1:4182/) с карточкой «Wave» или [плеер](http://127.0.0.1:4182/wave/). Чтобы оценки аккаунтов сохранялись между запусками, используйте один и тот же закрытый каталог данных.

## 2. Каталог и оценки

Стартовый каталог и теги лежат в [catalog.json](site/catalog.json). Клипы по лицензии CC BY 3.0 воспроизводятся с Wikimedia Commons через HTML5-плеер. Нажмите на название трека в нижней панели, чтобы посмотреть авторство, источник и лицензию. Добавляя клип, задайте уникальный стабильный ID и укажите автора и страницу файла. Заставка создана в ImageGen.

Оценки гостя хранятся в браузере. При регистрации и входе гостевые оценки дополняют оценки аккаунта. Если один клип уже оценён в аккаунте, сохраняется оценка аккаунта. Повторное нажатие снимает оценку. Для регистрации нужны имя пользователя и пароль. Восстановление пароля через почту не предусмотрено.

## 3. Проверки и сборка

```bash
node --test apps/wave/tests/selection.test.mjs
npm run test:wave:api
npm run build:sites -- wave
```

Сборка создаёт `apps/wave/dist/` для PHP-хостинга. Адрес, расположение базы и порядок поставки описаны в [инструкции публикации](deployment.md).
