# Агентская обвязка

## 1. Источник правил

[AGENTS.md](../AGENTS.md) содержит общие требования. Skills описывают отдельные процедуры, роли — ответственность исполнителей. Адаптеры Codex, Claude Code и Cursor ссылаются на эти источники. Основа перенесена и адаптирована из ContentAI-Frontend без корпоративных интеграций, библиотек и требований к стеку.

| Skill                                                  | Когда применять                                              |
| ------------------------------------------------------ | ------------------------------------------------------------ |
| [dev-cycle](skills/dev-cycle/SKILL.md)                 | Рабочий цикл, владение папкой и передача работы              |
| [design-and-docs](skills/design-and-docs/SKILL.md)     | Исследование, требования, технические решения и документация |
| [build-and-test](skills/build-and-test/SKILL.md)       | Проверки, тесты, браузер и доказательства из CI              |
| [simplify-solution](skills/simplify-solution/SKILL.md) | Упрощение решений и удаление доказанно неиспользуемого кода  |
| [github](skills/github/SKILL.md)                       | GitHub Issues, ветки, PR и Actions                           |
| [timeweb](skills/timeweb/SKILL.md)                     | Проверка SSH и публикация приложения на виртуальном хостинге |

| [claude-api](skills/claude-api/SKILL.md) | Интеграции Claude API в выбранном приложении |

[Исследование и предложения](../docs/designs/agent-harness.md) описывают причины изменений и сценарии оценки.

## 2. Роли и среды

[planner](roles/planner.md) исследует и планирует без записи, [coder](roles/coder.md) реализует порученные файлы, [reviewer](roles/reviewer.md) проверяет результат без записи. Роли наследуют выбранную модель. Их наличие не запускает подагентов автоматически и не меняет разрешения среды.

Claude Code читает `CLAUDE.md`, Codex и Cursor — `AGENTS.md`. Сведения о подключениях и доступах находятся в [GitHub](../docs/github.md) и [Timeweb](../infra/timeweb/README.md).

## 3. Форматирование

Хук [format-touched.cjs](hooks/scripts/format-touched.cjs) обрабатывает пути из событий сред и форматирует только эти существующие файлы через ближайший установленный Prettier. Чужие пути, символьные ссылки за пределы проекта, настройки подключений и файлы секретов пропускаются. Хук не ищет форматтер в соседних приложениях и не устанавливает пакеты.

Конфигурации находятся в `.codex/hooks.json`, `.claude/settings.json` и `.cursor/hooks.json`. Активация Codex зависит от поддержки hooks в установленной версии и пользовательской настройки. Файлы конфигурации в репозитории сами по себе не подтверждают запуск хука. Ошибка форматирования выводится в stderr, но не блокирует редактирование. Обязательная проверка выполняется командой `npm run format:check` и в CI.
