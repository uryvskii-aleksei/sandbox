# Wave

Видеорадио Amodu. Запустите первый клип кнопкой Play на нижней панели или нажатием на кадр видео. Подсказки показывают клавиши управления: пробел — воспроизведение или пауза, ← и → — предыдущий и следующий клип, L и D — лайк и дизлайк, I — сведения о клипе, F — полноэкранный режим. Стартовый клип выбирается случайно с учётом имеющихся оценок. Кадр, исполнитель и название выбранного клипа видны ещё до запуска. Стартовый кадр загружается отдельным изображением, чтобы показываться и на телефонах до начала воспроизведения. Рамка подстраивается под пропорции клипа, чтобы показать весь кадр. После него включается следующий. Можно поставить клип на паузу, вернуться к предыдущему и оценить текущий. Похожие клипы появляются чаще после лайков и реже после дизлайков. При подборе учитываются исполнитель и теги. Цветовая палитра клипа применяется к кнопкам, фигурам и фону. Во время воспроизведения цветовые пятна плавно перемещаются, меняя яркость в такт музыке. Волны, дуги, точки и штрихи реагируют на бас и частоты. Мягкое свечение идёт от краёв экрана к центру и пульсирует на басовых ударах. Для каждой сцены Wave заново сочетает два вида фигур, меняет их форму, расположение и движение. Сцены плавно сменяют друг друга. На паузе и при системной настройке уменьшенного движения фон сохраняет оттенок клипа без анимации.

## 1. Локальный запуск

Нужен PHP 8.2+ с PDO SQLite. Из корня монорепозитория запустите:

```bash
wave_data="$(mktemp -d)"
WAVE_DB_PATH="$wave_data/wave.sqlite3" php -S 127.0.0.1:4182 -t apps/wave/site apps/wave/preview.php
```

Откройте [главную Amodu](http://127.0.0.1:4182/) с карточкой «Wave» или [плеер](http://127.0.0.1:4182/wave/). Чтобы оценки аккаунтов сохранялись между запусками, используйте один и тот же закрытый каталог данных.

## 2. Каталог и оценки

Стартовый [каталог](site/catalog.json) объединяет Wikimedia Commons и RUTUBE. У Wikimedia Commons свои видеофайлы и атрибуция по Creative Commons. Внешние источники используют встроенные плееры и показывают авторство и ссылку на оригинал в окне «О клипе». У встроенных плееров цвет и движение фона привязаны к состоянию воспроизведения. Анализ звука доступен для клипов Wikimedia Commons.

Стартовый каталог включает архивные клипы из каналов музыкальных лейблов на RUTUBE. При посещении Wave сервер примерно раз в час проверяет две последние страницы тех же каналов. Он добавляет новые клипы по их ID и хранит обновления в закрытой SQLite. Повторное появление клипа в ленте не увеличивает каталог. При сбое доступны стартовый каталог и последнее успешное обновление. Для обновления нужно расширение PHP cURL. Wave показывает плеер RUTUBE после подтверждения доступности ролика. При сбое загрузки приложение переключается на следующий клип и исключает ролик со сбоем из текущего сеанса. Добавляя клип, сохраняйте уникальный стабильный ID, указывайте автора и используйте официальный код встраивания или ссылку на файл с его лицензией.

Лайк повышает частоту клипов того же исполнителя, его совместных работ и близких жанров. После дизлайка Wave реже рекомендует похожие песни и исключает совпадающие копии песни в других источниках. Если есть доступная замена, Wave сразу переключает клип. Жанровые хештеги из публикации учитываются прежде общих тегов канала. Распространённые теги слабее влияют на выбор, а часть подборки остаётся для открытия новой музыки. Недавно включённые клипы запоминаются в браузере и после перезагрузки. Повторное нажатие на оценку снимает её.

Похожие клипы появляются реже после быстрого перехода к следующему клипу, если воспроизвелось от 1 до 10 секунд и не больше половины ролика. Если клип закончился сам и было просмотрено хотя бы 85% видео, похожие клипы появляются чаще. Перемотанные отрезки, реклама и ошибки загрузки не учитываются. Лайк и дизлайк влияют на подборку сильнее. Wave хранит последний учтённый результат по клипу.

Оценки и результаты просмотра гостя хранятся в браузере. При регистрации и входе они дополняют данные аккаунта. Для уже учтённых клипов сохраняются данные аккаунта. Для регистрации нужны email и непустой пароль. Email используется для входа и не требует подтверждения. Ранее созданные аккаунты по-прежнему открываются по имени пользователя. Восстановление пароля через почту не предусмотрено.

## 3. Проверки и сборка

```bash
node --test apps/wave/tests/selection.test.mjs
npm run test:wave:api
npm run build:sites -- wave
```

Сборка создаёт `apps/wave/dist/` для PHP-хостинга. Адрес, расположение базы и порядок поставки описаны в [инструкции публикации](deployment.md).
