# Документация

## 1. Материалы

- [Разработка](development.md): границы приложений, рабочий процесс и проверка результата.
- [GitHub](github.md): подключение агента, авторизация и CI.
- [Timeweb](../infra/timeweb/README.md): SSH и публикация на виртуальном хостинге.

- [Импорт приложений](imports/README.md): происхождение файлов и сохранение истории.
- [Развитие обвязки](designs/agent-harness.md): источники, принятые изменения и предложения.

## 2. Технические решения

Долговременные решения храните в `docs/designs/<имя>.md` или рядом с приложением, которому они принадлежат. Записывайте задачу, выбранный вариант, существенные альтернативы, контракты и проверку. Планы текущей работы остаются в PR или чате.
