# MindAssistant

## 1. Приложение

Личное пространство с проектами, связанными карточками и полотном с перемещением и масштабом. В карточке — упорядоченные сворачиваемые группы и поля: текст, ссылка, дата, изображение, видео, аудио. Поддерживаются регистрация, вход, приватные проекты, загрузка медиа до 5 МБ и превью публичных ссылок.

Новый стек: React + TypeScript + Vite, PHP 8.4 + MySQL 8.4. Старые Angular/Go-исходники с лицензиями находятся в `legacy/` и не подключены к npm workspaces.

## 2. macOS и Docker

Нужны Node.js 24+, npm и запущенный Docker Desktop с Compose. React/Vite работает на macOS. PHP/Apache и MySQL — в Docker. Порт MySQL наружу не открыт, API привязан к `127.0.0.1:8081`.

Из корня Sandbox:

```bash
npm ci
npm run dev:mind-assistant
```

Откройте `http://127.0.0.1:5173/mind-assistant/`. Первый запуск создаёт игнорируемый `.env` со случайным локальным паролем, собирает контейнер, запускает MySQL, применяет схему и запускает Vite. Данные сохраняются в Docker volume `sandbox-mind-assistant_mysql-data`. При остановке Vite контейнеры продолжают работать.

```bash
npm run services:down --workspace=@sandbox/mind-assistant
npm run services:up --workspace=@sandbox/mind-assistant
npm run db:migrate --workspace=@sandbox/mind-assistant
```

`services:down` сохраняет volume. `docker compose down --volumes` удаляет локальные данные, поэтому для обычной остановки он не используется. Изменения React обновляются через Vite. PHP подключён в контейнер как исходники только для чтения, изменения видны при следующем запросе. Dockerfile требует пересборки образа после изменения зависимостей PHP.

## 3. Проверки и сборка

```bash
npm run check --workspace=@sandbox/mind-assistant
npm run build:mind-assistant
npm run test:mind-assistant
```

Интеграционный тест создаёт отдельный Compose-проект со случайным паролем, свободным портом и собственной БД. Проверяет синтаксис PHP, повторное применение схемы, авторизацию/CSRF, владение данными, все типы полей, порядок, сохранение между сессиями, конфликты версий, транзакционный rollback, удаление связанных карточек и безопасность медиа/URL-превью. Дополнительно запускает собранный артефакт в Apache, проверяет вложенные маршруты, ресурсы, запрет доступа к серверным файлам и повторяет API-сценарий под `/mind-assistant/api`. После проверки удаляет только свои тестовые контейнеры и volume. Рабочая БД приложения не очищается.

Сборка `dist/` содержит React, PHP API, схему и защищённые Apache-каталоги. Исходники legacy, Docker и `.env` туда не попадают.

## 4. Устройство API

Frontend обращается к `/mind-assistant/api/`. Vite проксирует запросы в локальный Apache. PHP использует native session с HttpOnly/SameSite cookie и CSRF-токен для записи. Запросы PDO параметризованы, доступ к проектам/карточкам/файлам проверяется по владельцу. Полное сохранение карточки выполняется в транзакции и проверяет версию для защиты от перезаписи устаревшего состояния.

Файлы хранятся в MySQL и выдаются только авторизованному владельцу. URL-превью ограничено публичными HTTP(S)-адресами с проверкой редиректов и фиксацией IP. Не предусмотрены сброс пароля, email-верификация, общий доступ и синхронное редактирование несколькими пользователями.

## 5. Timeweb

На хостинге Docker и Node не нужны: Apache/PHP обслуживает API, MySQL хранит данные, React загружается как готовые файлы. Базовый путь сборки — `/mind-assistant/`. Публикация требует отдельного каталога, MySQL-базы и конфигурации. Подробности — в [инструкции поставки](deployment.md).

## 6. Старые данные

Прежние репозитории сохранены в `legacy/frontend/` и `legacy/backend/`. PostgreSQL-дамп хранится приватно вне Git, см. [происхождение](../../docs/imports/README.md). Новая схема содержит пользователей и владельцев проектов. В сохранённом дампе все четыре таблицы пустые, поэтому пользовательских записей для конвертации нет. Новое приложение начинает с пустой БД.
