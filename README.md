# Sandbox

Личный монорепозиторий [uryvskii-aleksei/sandbox](https://github.com/uryvskii-aleksei/sandbox) для независимых приложений и публикации на личном домене через виртуальный хостинг Timeweb.

## 1. Структура

| Каталог                                   | Назначение                                                    |
| ----------------------------------------- | ------------------------------------------------------------- |
| [apps/](apps/README.md)                   | Отдельные приложения со своим стеком и инструкциями           |
| [packages/](packages/README.md)           | Общий код, который действительно нужен нескольким приложениям |
| [infra/timeweb/](infra/timeweb/README.md) | SSH, адреса публикации и команды работы с Timeweb             |
| [.agents/](.agents/README.md)             | Общие skills, роли и хук форматирования                       |
| [docs/](docs/README.md)                   | Документация разработки и принятые технические решения        |
| [.github/](.github/README.md)             | GitHub Actions и шаблоны задач и PR                           |

В репозитории находятся Purpur, Stone Haus и MindAssistant. Исходники сайтов, история и документы перенесены из прежних проектов. [Состав и команды приложений](apps/README.md), [происхождение импорта](docs/imports/README.md).

## 2. Локальная подготовка

Нужны Git, Node.js 24+, npm и Python 3.10+ для проверок поставки. Для Timeweb нужны SSH и rsync, для GitHub CLI при его использовании — `gh`.

```bash
npm ci
npm run check
npm run doctor
```

`check` проверяет обвязку, синтаксис сайтов, перенесённые тесты, типы React и форматирование. `npm run build:sites` и `npm run build:mind-assistant` создают сборки. Для MindAssistant на macOS запустите Docker Desktop и `npm run dev:mind-assistant`. Интеграционные проверки PHP/MySQL: `npm run test:mind-assistant`.

## 3. Агентская обвязка

[AGENTS.md](AGENTS.md) содержит общие правила. Skills и роли адаптированы из ContentAI-Frontend: рабочий цикл, владение рабочей папкой, планирование, проверка поведения, документация, упрощение решений и форматирование изменённых файлов. Корпоративные сервисы, пакеты и ограничения стека не перенесены.

Поддерживаются Codex, Claude Code и Cursor. Канонические инструкции находятся в `.agents/`, файлы сред ссылаются на них. GitHub подключён через официальный плагин, доступ аккаунта к репозиторию проверен. Настройка подключений описана в [GitHub](docs/github.md) и [Timeweb](infra/timeweb/README.md). Личные настройки IDE не входят в репозиторий.

```text
Исследуй варианты приложения и предложи решение без реализации.
Реализуй приложение в apps/<имя> и проверь результат локально.
Подготовь PR по issue #<номер> и дождись проверок.
Покажи план публикации <цель> на Timeweb.
```

Skills не создают разрешение на внешние действия. Локальная разработка, PR и публикация имеют тот объём, который задан в поручении.

## 4. Разработка и публикация

Основная ветка — `main`. Рабочий порядок: задача → ветка → реализация → проверки → PR → публикация выбранного приложения. Для небольшого локального изменения issue и PR не обязательны. Подробнее — [правила разработки](docs/development.md).

Timeweb — обычный виртуальный хостинг с SSH/SFTP. Текущий технический домен и подключение записаны в [инструкции Timeweb](infra/timeweb/README.md). SSH, SFTP и передача через rsync проверены. Команда `npm run timeweb -- check` проверяет доступ к хостингу. [Реестр статических целей](infra/timeweb/targets.json) пока пуст: импорт существующих сайтов не включает их повторную публикацию. MindAssistant имеет отдельную [процедуру PHP/MySQL](apps/mind-assistant/deployment.md).

GitHub Actions проверяет обвязку, сайты и MindAssistant, включая PHP 8.2/8.4 с MySQL. Проверенный коммит `main` выпускается на [MindAssistant](https://cj999935.tw1.ru/mind-assistant/) командой `npm run release:mind-assistant`. Workflow публикует артефакт, задание Timeweb забирает его по HTTPS и подтверждает результат. Обычный push в `main` выполняет только проверки. SSH-ключи и пароль MySQL остаются вне GitHub.
