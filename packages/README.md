# Общие пакеты

## 1. Назначение

Общий код для нескольких приложений размещается в `packages/<имя>`. Общих пакетов пока нет. Создавайте пакет при появлении реального общего потребителя или самостоятельного контракта.

## 2. Границы

У пакета есть свой README, публичный интерфейс и необходимые проверки. Пакет не зависит от приватного кода приложения. Команды JavaScript-пакетов запускаются через корневой npm workspace. Зависимости потребителей и изменение публичного контракта проверяются вместе с пакетом.
