# Stone Haus

Концепция сайта по публичным сведениям [stonehaus.ru](https://stonehaus.ru/) на 30 октября 2026 года. Цен на той странице нет, поэтому их нет и здесь. Заявка не отправляется, оплата не проходит, дом не бронируется.

| Версия | Исходники | Стенд |
| --- | --- | --- |
| v1 | `public/` | [cj999935.tw1.ru/stonehaus/v1/](https://cj999935.tw1.ru/stonehaus/v1/) |
| v2 | `v2/` | [cj999935.tw1.ru/stonehaus/v2/](https://cj999935.tw1.ru/stonehaus/v2/) |

v2 — продуктовая страница. Тексты и три ролика взяты с stonehaus.ru и встроены с Rutube: «Обзор дома 2.0», «КП Ропшинские высоты», «КП Зеленый Хутор». Файлы роликов в репозиторий не копируются. Фотографии построенного дома и 3D-визуализация мебели подписаны по-разному.

Локально из каталога `apps/stonehaus`: `python3 -m http.server 4175`, затем `http://127.0.0.1:4175/v2/`.
